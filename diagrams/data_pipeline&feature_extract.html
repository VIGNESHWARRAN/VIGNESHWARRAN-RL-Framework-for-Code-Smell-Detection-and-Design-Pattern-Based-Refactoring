SmellRL Data Pipeline & Feature Extraction

End-to-end data flow from raw CSV to the 128-dimensional Attributed Heterogeneous Graph Tensor

1. Data Preparation
Ingestion, validation, and balancing
Raw MLCQ CSV
Java source code matched with expert-annotated structural and semantic smell labels.
↓
AST Parse Validation
Parallel processing via javalang. Unparseable rows are filtered and cached to disk.
↓
Class Balancing
NoSmell instances are dynamically downsampled (3.0× ratio) to prevent severe class imbalance during RL.
→
2. Heterogeneous Graph Construction
783-dimensional node features & structural edges
Node Type 3 dims
One-hot encoding for Class (0), Method (1..M), or Field (M+1..M+F).
CK Metrics 6 dims
Normalized structural data: WMC, DIT, NOC, CBO, RFC, LOC.
Data Usage 6 dims
Frequencies of field accesses, method calls, and external objects.
Semantic 768 dims
[CLS] token extracted via microsoft/graphcodebert-base.
Heterogeneous Edges:
CONTAINS Class ↔ Methods & Fields
CALLS Method → Method
ACCESSES Method → Field
→

Asymmetric compression to prioritize structure
Structural Branch
Linear(15→48) → ReLU → Linear(48→96)
96 dims
Semantic Branch
Linear(768→32) → LayerNorm
32 dims
↓ ⊕ ↓ Concat
Fused Node Vector
128 dimensions per node.
(75% structural capacity)
→
4. Output
Serialization to disk
Attributed Graph Tensor

edge_index: [2 × E]
